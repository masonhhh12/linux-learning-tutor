# Linux Learning Tutor v1.0.0 — draft

A local learning application combining six guided Linux lessons with
Ollama-powered AI tutoring.

## Included
- SQLite accounts, Argon2id password hashes, and revocable cookie sessions.
- Navigation, files, text reading, search, permissions, and pipes lessons.
- Multiple-choice practice and browser-local completion tracking.
- Streamed AI answers and context from six completed exchanges.
- New chat control, API documentation, and a startup script.
- 31 automated API and authentication tests, setup guide, architecture, and demo script.

## Requirements
Ubuntu/WSL, Python 3.12, Ollama, and the llama3.2 model.
No paid API key or frontend build step is required.

## Limitations
Local authenticated prototype without hosted deployment.
Chat is cleared on refresh. Progress is browser-local.
Model output can be inaccurate and CPU inference can be slow.
Commands are displayed as examples and are never executed by the app.
